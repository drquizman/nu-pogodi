# Ну, погоди! — Motion Edition

## Играть онлайн

Откройте https://drquizman.github.io/nu-pogodi/ на большом экране и сканируйте QR телефоном. Разрешите камеру, отойдите и держите руки-корзину три секунды. Регистрация не нужна. Домашний сервер и временный туннель для этой версии не нужны.

Исходники: https://github.com/drquizman/nu-pogodi. Связь устройств работает через отдельный Supabase `nu-pogodi-motion`; проекты DrQuizman не затрагиваются. Подробности облачной сборки — в [DEPLOY-SUPABASE.md](DEPLOY-SUPABASE.md).

Под полем показаны общие счётчики всех игроков. Партия засчитывается один раз при первом пойманном яйце, пойманные и разбитые яйца учитываются по ходу игры (включая промахи до первого улова). Статистика собирается с момента установки обновления. Повторные отправки результата не создают дублей; при временной потере сети браузер сохраняет неподтверждённые результаты и повторяет отправку, пока действительна комната (24 часа). В локальном режиме показываются отдельные счётчики этого браузера.

Рабочий прототип: Windows показывает игру, Android распознаёт движения через фронтальную камеру. Телефон стоит возле большого экрана. Человек виден по пояс, обе руки изображают корзину. Видео обрабатывается локально в Web Worker и не отправляется на сервер.

## Запуск на Windows

Установленный Node.js 22+. Двойной щелчок по `Играть.bat` устанавливает зависимости, подготавливает модель, собирает игру и запускает временную HTTPS-ссылку через Cloudflare Quick Tunnel. Откройте адрес из строки `OPEN GAME` на компьютере. Сканируйте QR с Android, откройте ссылку в Chrome, разрешите камеру. Консоль должна оставаться открытой. При перезапуске ссылка меняется. Интернет нужен на обоих устройствах. Туннель даёт доступ только к игровому серверу; ссылка доступна любому, кто её знает. Управление отдельной комнатой требует случайного ключа из QR-кода.

Поставьте телефон устойчиво камерой к себе и убедитесь, что пояс и руки не обрезаны. Нажмите «Включить камеру и играть», отойдите и держите корзину перед собой три секунды. Подключённый телефон выбирается автоматически: корзина повторяет движения ещё до начала игры. Настройки объектива и необязательная калибровка спрятаны в разделе «Настроить камеру».

На телефоне раздел «Камера и угол обзора» позволяет выбрать любой объектив, который браузер показывает после разрешения камеры. При открытии камеры запрашиваются кадр без дополнительной обрезки и минимально допустимый аппаратный масштаб. Кнопка «Максимальный обзор» повторяет запрос. Это не создаёт широкоугольную оптику: объектив 0,5× может быть недоступен браузеру, даже если он есть в штатном приложении камеры. Положение телефона горизонтально даёт больше места для рук по сторонам. Видео и скелет сохраняют фактические пропорции кадра.

Индикатор на телефоне подтверждает получение движений именно игровым экраном, а не только сервером. QR-код расположен по центру игрового поля и скрывается после подключения. Боковой панели нет.

Звук включён по умолчанию. Игра пробует запустить его сразу; если браузер блокирует автозапуск, достаточно любого нажатия или клавиши на компьютере. Во время игры звучит оригинальная синтезированная мелодия; у появления, качения, ловли и разбивания яиц свои эффекты. Музыка затихает на паузе. Та же кнопка отключает все звуки.

Клавиатура: Q/A — слева сверху/снизу; E/D — справа сверху/снизу. Enter — начало, пробел — пауза. Три промаха завершают попытку. Рекорд хранится только в браузере.

## Разработка

```powershell
npm.cmd install
node scripts/assets.mjs
npm.cmd run dev
```

Адрес: http://localhost:17891. Камера на телефоне по локальному HTTP не работает: используйте HTTPS-запуск выше. Сервер слушает только loopback. Для клавиатуры интернет и камера не нужны после установки.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd start
```

Проверка работающего сервера: `node scripts/check-relay.mjs`. Проверка полного пути до браузерной игры: откройте свежую тестовую комнату на компьютере и выполните `node scripts/check-host.mjs "ССЫЛКА_ПУЛЬТА"`. Проверка занимает слот телефона в этой комнате; не используйте комнату реального игрока. Проверяются все четыре направления без калибровки, автоматический выбор камеры, старт, потеря позы и восстановление.

## Архитектура

- `src/core/game.ts`: переносимое ядро; фиксируем входные команды, используем переданное время и источник случайности. Нет DOM, сети или браузерных часов.
- `src/core/pose.ts`: нормализация по корпусу, калибровка и пороги переключения.
- `src/renderer.ts`: Canvas-отрисовка, рисованные спрайты и точное совмещение дорожек с корзиной.
- `src/phone.ts`, `src/pose-worker.ts`: камера, локальное распознавание MediaPipe Lite, обучение четырём позициям.
- `server/index.ts`: комнаты в памяти, криптографические ключи ролей, WebSocket relay, переподключение и heartbeat. Ключ телефона передаётся в URL-фрагменте, не в HTTP query.
- `scripts/play.mjs`: временный HTTPS-туннель. Для постоянного выпуска нужен собственный сервер и домен с TLS; Quick Tunnel — средство демонстрации без гарантии доступности.

Потеря позы/сети ставит игру на паузу, восстановление — обратный отсчёт. Ручная пауза автоматически не снимается. Модель, WASM и интерфейс обслуживаются с того же адреса; шрифты имеют системный fallback.

## Границы прототипа

Один человек, фронтальная камера, четыре позиции. Полупоясной ракурс и производительность распознавания требуют проверки на физическом телефоне. Есть автоматические тесты ядра; они не заменяют тест камеры. iPhone, Android TV, Samsung Tizen и Apple TV ещё не проверены и не упакованы. Для tvOS планируется отдельная отрисовка SpriteKit и выполнение ядра JavaScriptCore; потребуется Mac/Xcode. Нельзя считать перенос проверенным до запуска на устройствах.

Волк, фон фермы, курицы и яйца созданы встроенным image_gen в согласованной рисованной стилистике. Исходные PNG и промпты сохранены в public/art. Это новые иллюстрации, а не оригинальные спрайты игры. Дорожки, табло и эффекты ловли отрисовываются Canvas поверх иллюстраций. MediaPipe Pose Landmarker Lite загружается с официального хранилища Google; WASM — из npm-пакета `@mediapipe/tasks-vision`.

## Старт без касания
После включения камеры отойдите, держите воображаемую корзину перед собой неподвижно 3 секунды. Затем на экране игры идёт обратный отсчёт. Потеря позы, отключение связи и калибровка прерывают удержание. После проигрыша сначала опустите руки, затем повторите жест, чтобы избежать случайного перезапуска.


## Перекрытие рук
После уверенного распознавания обеих кистей при потере одной из них управление до 2 секунд продолжается по видимой кисти с сохранённым смещением центра корзины. При краткой потере обеих кистей последнее положение удерживается до 350 мс. Перекрытый локоть не блокирует видимые кисти. Потеря корпуса сразу сбрасывает историю; длительная потеря рук вызывает обычную паузу. Для калибровки и запуска жестом нужны реально видимые обе кисти, восстановленные координаты там не используются.
