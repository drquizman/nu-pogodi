# GitHub Pages + отдельный Supabase

Игра: https://drquizman.github.io/nu-pogodi/

Публичный репозиторий: https://github.com/drquizman/nu-pogodi. Ветка `main` содержит исходники, `gh-pages` — готовый сайт. GitHub Pages публикует `gh-pages` / `(root)` с HTTPS. При обновлении игры нужно пересобрать облачную версию и загрузить содержимое `dist` в `gh-pages`; один push исходников в `main` сайт не обновляет.

Проект игры: nu-pogodi-motion (dmhdfjdullccoheavcec), регион eu-central-1.
DrQuizman не используется: у игры свои таблицы np_rooms/np_members, функции RPC, пользователи и политики Realtime.

## Связь

Посетитель получает анонимную сессию Supabase, без формы регистрации. При создании комнаты генерируются отдельные случайные ключи экрана и телефона. В базе хранятся только их хеши. Ключ пульта передаётся в URL-фрагменте. Подключение к комнате требует правильного ключа роли.

Два закрытых канала Realtime разделяют команды экрана и телефона. Правила RLS разрешают чтение только участникам комнаты, а отправку — только в канал своей роли. Видео остаётся на телефоне. Комната действительна 24 часа; затем нужно обновить страницу игры и сканировать новый QR.

Бесплатный Supabase имеет лимиты активности и может приостанавливать неактивный проект. Это облачное размещение без домашнего компьютера, но не обещание непрерывной доступности бесплатного тарифа.

## Сборка

Скопировать .env.example в .env.cloud и добавить публичный anon key этого проекта (не service_role).

PowerShell:

```
$env:VITE_PUBLIC_BASE='/nu-pogodi/'
npm.cmd ci
node scripts/assets.mjs
npm.cmd run build -- --mode cloud
```

На GitHub Pages публикуется только содержимое dist, с файлом .nojekyll. Репозиторий исходников и проект Supabase должны оставаться отдельными от DrQuizman.

Для локального режима без Supabase убрать VITE_PUBLIC_BASE и запустить обычный npm run build / Играть.bat.

## Проверки

- npm test — игровое ядро, камера, старт жестом, перекрытие рук, совмещение картинок.
- node scripts/check-cloud.mjs — реальная доставка команд и изоляция ролей/комнат в тестовых комнатах нового проекта.
- node scripts/check-cloud-host.mjs "ССЫЛКА_ТЕСТОВОГО_ПУЛЬТА" — движение в открытой вкладке, запуск и пауза через Supabase. Не запускать на комнате текущего игрока.

Секретный пароль базы сохранён локально в .runtime под защитой Windows DPAPI. Он не входит в репозиторий или сайт. .env.cloud также исключён из Git; публичный anon key при сборке входит в браузерный JavaScript, это штатный механизм Supabase. Секретные ключи сервисной роли не используются клиентом.
